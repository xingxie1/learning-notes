## 我的起点与目标

现在是大三上，因为区域赛没有名额，决定结束 ACM 竞赛训练，把时间转向计算机基础、考研和就业准备。过去的算法训练可以继续服务于数据结构、编程和面试，不必重新从编程入门学起。

这份计划以 [CS 自学指南](https://csdiy.wiki/) 为资源入口，学习重点是操作系统、计算机组成原理和计算机网络。近期目标是把系统知识学扎实，并做出能自己解释、调试和复现的实验；后续按考研进度逐步增加应试训练。

**暂定前提：** 按常见四年制进度，计划参加大四上、即 2027 年末的考研初试，具体考试日期以官方通知为准；每周可投入约 28 小时课外学习；有 C++ 和算法基础，但 C 指针、Linux 和系统编程需要检查。目标院校、专业课科目和就业方向尚未确定，先按系统基础通用路线推进。

如果实际备考的是 2026 年末考试，应立即改为考试优先，暂停下面的大型实验，不照搬这份时间表。

## 总体路线与取舍

**C / Linux 工具补齐 → CSAPP 系统基础 → 计组重点补齐 → 操作系统理论与 xv6 实验 → 计网与网络编程。** 数学、英语从第一周并行推进。

每次只推进一门系统主课。课程用于建立理解，考试教材与习题用于补齐考点，实验用于验证理解。同一主题不重复看多套完整视频；先看书和课件，遇到疑问再找对应视频。

CS 自学指南是资源地图，不是必须全部完成的清单。本计划只选部分章节和实验，时间预算是个人安排，不代表完整课程所需学时。

| 方向 | 主资源 | 必做部分 | 后续选做 |
| --- | --- | --- | --- |
| 系统基础 | CSAPP 第三版 / CMU 15-213 | 数据表示、机器级程序、存储层次、链接；Data Lab、Cache Lab | Bomb Lab；Shell Lab 放在操作系统阶段；Malloc Lab 暂缓 |
| 计组 | CS61C 选讲 + 考试对应教材 | RISC-V 基础、组合/时序逻辑、数据通路、流水线、Cache；按考纲补运算器、控制器、总线与 I/O | Logisim 小型数据通路；完整 CPU 项目暂缓 |
| 操作系统 | OSTEP 选读 + MIT 6.1810 / 6.S081 | 进程、调度、虚拟内存、同步、文件系统；xv6 入门与若干实验 | 更完整的 xv6 实验，考后继续 |
| 计网 | 中科大郑烇《计算机网络：自顶向下方法》+ 对应教材 | 分层、HTTP/DNS、TCP/UDP、IP/路由、链路层；抓包、Socket 小程序 | CS144 的 TCP 实现留作进阶 |

CSAPP 中的机器级程序主要学习 x86-64，CS61C 和 xv6 路线涉及 RISC-V。重点是理解指令、调用约定和地址访问，不要求同时熟练写两套汇编。

## 第一阶段：24 周打基础

从 2026 年 9 月末开始，预计推进到 2027 年 3 月中旬。按周验收；期末考试和学校作业占用较多时，减少选做内容或顺延，不挤占睡眠补进度。

| 周次 | 学习主题 | 实践与输出 | 完成标准 |
| --- | --- | --- | --- |
| 第 1—2 周 | C 指针、数组、结构体、内存分配；Linux、Git、编译与调试 | 写一个 C 链表或动态数组，用 GDB 定位一次错误；建立实验记录 | 能解释栈/堆区别，独立编译、运行和调试程序 |
| 第 3—6 周 | CSAPP 第 1—3 章重点：数据表示、整数/浮点、汇编与函数调用 | Data Lab；反汇编一个小程序，标注参数传递和栈帧；Bomb Lab 选做 | 能解释补码、溢出、指针访问和一次函数调用 |
| 第 7—9 周 | CSAPP 第 6—7 章：Cache、局部性、链接；第 5 章按需选读 | Cache Lab；比较两个遍历程序的性能；观察目标文件与链接结果 | 能做 Cache 地址划分题，解释局部性与链接流程 |
| 第 10—12 周 | CS61C 选讲：RISC-V、数字逻辑、CPU 数据通路、流水线；补考研计组遗漏 | 画一条指令的执行路径；做流水线、存储器、总线/I/O 专项题 | 能分析冒险、CPI、存储容量和访存时间；列清遗漏考点 |
| 第 13—14 周 | 操作系统：进程、系统调用、调度；CSAPP 第 8 章配合阅读 | fork/exec/wait 小程序；xv6 utilities 和 system calls 实验 | 能解释进程创建、程序替换、用户态/内核态切换 |
| 第 15—16 周 | 地址空间、页表、TLB、缺页；CSAPP 第 9 章与 OSTEP 选读 | xv6 page tables 实验；画地址翻译路径；基础扎实时再做 COW | 能区分 Cache 与 TLB、虚拟地址与物理地址，完成页表题 |
| 第 17—18 周 | 并发、锁、条件变量、死锁、文件系统与 I/O | 写生产者—消费者程序；用实验或源码追踪理解锁和文件访问；Shell Lab 选做 | 能说明竞态原因、同步方案、死锁条件及文件系统基本结构 |
| 第 19—20 周 | 计网概览、应用层、传输层：HTTP、DNS、TCP/UDP、可靠传输与拥塞控制 | 抓取自己产生的 DNS/HTTP 流量，观察 TCP 建连与传输 | 能沿着一次请求解释协议分工，说明可靠传输与流量/拥塞控制 |
| 第 21—22 周 | 网络层、链路层：IP、子网、路由、ARP、交换、差错检测 | 做子网与时延题；写 TCP 客户端/服务端，正确处理消息边界 | 能区分交换机与路由器，完成子网、窗口和传输时延计算 |
| 第 23—24 周 | 串联计组、OS、网络；补数据结构理论漏洞 | 整理综合项目和实验 README；做三科混合自测 | 能讲清“程序如何执行”和“请求如何完成”，错题能归因并订正 |

操作系统阶段选用同一届 MIT 课程的代码、教材和实验说明，例如 [2025 年课程日程](https://pdos.csail.mit.edu/6.1810/2025/schedule.html)。不同年份实验会变化，按所选版本安排，不强求实验名和数量完全一致。

## 每周时间怎么分

下列 28 小时是正常教学周的课外预算，学校课程、作业和考试另行安排。先执行两周，按实际完成量调整。

| 内容 | 每周时间 | 执行方式 |
| --- | --- | --- |
| 系统主课与实验 | 14 小时 | 约 5 小时阅读/课程、6 小时动手、3 小时考点与习题 |
| 考研数学 | 7 小时 | 每周 5—6 次；先诊断高数和线代，按目标考试科目补基础并做题 |
| 英语 | 4 小时 | 每天约 30 分钟词汇与阅读，保留一次精读和长难句复盘 |
| 数据结构与算法 | 2 小时 | 每周 2—3 道基础或面试题；补树、图、查找、排序的理论与手算题 |
| 周复盘 | 1 小时 | 检查成果、错题、实际耗时，排下一周最重要的三件事 |

参考安排：周一至周五每天约 3 小时，周六 7 小时，周日 6 小时，分段完成并保留休息。实验至少安排一次连续 2—3 小时的时段。

**忙碌周最低版本：** 系统基础 6 小时、数学 4 小时、英语 2 小时、复盘 30 分钟。数据结构并入专业课习题；暂停选做实验。若连续两周达不到正常预算，就拉长阶段，不把所有欠账堆到周末。

## 考研这条线怎么接上

### 大三上到寒假：理解基础，尽早确定考试范围

- 数学和英语持续推进；不要等系统课学完才开始。
- 用 2—4 周筛选少量目标院校与专业，查看招生单位官网的招生目录、专业课范围与参考书，记录来源和年份。
- 专业课暂按包含数据结构、计组、操作系统、计网的 408 范围建立知识目录；若目标是自命题，再按官方范围调整。
- 对每个主题保留一页“概念—典型题—实验现象”笔记。学完国外课程后，仍需用目标考纲检查覆盖情况。

### 大三下：从理解转向完整覆盖

第一阶段结束后，以考试对应教材和习题组织专业课第一轮，补数字运算、I/O、调度计算、磁盘、链路层等薄弱部分。ACM 经历不等于数据结构考试没有漏洞，仍需练习定义、性质、复杂度分析和手算过程。

建议每周预算调整为数学 10 小时、英语 5 小时、专业课 10 小时、项目维护/方向探索 2 小时、复盘 1 小时。目标是到暑假前建立完整考点目录，并完成一轮章节习题，而不是以“视频看完”作为结束条件。

### 暑假到大四上：明确主目标

如果考研是第一优先级，暑假增加数学与专业课的综合训练，逐步做限时题与真题，政治按当年的备考安排加入；秋季主要做套卷、错题回访和记忆巩固。大型实验暂停，现有项目只维护。

如果决定就业优先，则把主要时间转向目标岗位的语言、开发框架、数据库、项目和实习/校招准备，考研安排另行缩减。不要同时把考研冲刺和求职项目都设为满负荷。

每月月底检查一次：目标是否明确、数学是否按计划推进、专业课错题是否减少、项目是否可运行。到大三下结束，应明确暑假和大四上的主目标。

## 就业准备：把基础变成可展示的能力

先暂定用 C/C++ 与 Linux 完成系统实验，最终岗位方向在学过 OS 和网络后决定。若转 Java 后端等方向，保留系统基础，后续补对应语言、框架与数据库；这份系统路线本身不能替代岗位开发训练。

第一阶段只保留一个综合项目：**基于 TCP Socket 的简易 HTTP/1.1 静态文件服务器**，按以下顺序迭代，不追求框架数量。

1. 单连接处理 GET 请求，返回固定页面，写清支持的请求范围。
2. 支持静态文件、404、基本日志，处理部分读写和断开连接；将文件访问限制在指定目录内。
3. 再加入多连接处理，解释进程/线程模型和共享数据同步；线程池作为选做。
4. 编写正常请求、缺失文件、异常输入和并发请求的验证步骤，记录环境、测试方法与结果。

先复用 CSAPP 或计网阶段的小程序，在第 23—24 周整理出能运行的第一版，更多功能放到后续。使用现成系统 TCP Socket；完整 TCP 协议实现暂留给 CS144 进阶。

项目验收看四点：能独立运行、能复现测试、能说明设计取舍、能解释并修复一个真实问题。README 应包含运行步骤、结构图、支持范围、测试记录和已知限制；简历只写自己完成并能回答细节的部分。

## 前两周直接执行

### 第一周：摸清基础并启动

- [ ] 写下目标考试年份、每周可用时间、已学课程与数学薄弱点。
- [ ] 使用已有 Linux 环境；没有则准备 WSL2/虚拟机，确认 C 编译器、GDB、Make、Git 能用。
- [ ] 用 C 写一个动态数组或链表，测试空输入和内存释放；定位并记录一次指针错误。
- [ ] 阅读 CSAPP 第 1 章，画出编译、汇编、链接、运行的流程。
- [ ] 做一次高数/线代小诊断；开始每天英语词汇与短篇阅读。
- [ ] 周末记录实际用时，确认 28 小时预算是否现实。

### 第二周：开始形成学习闭环

- [ ] 复习位运算、补码、整数转换和浮点表示，阅读 CSAPP 第 2 章重点。
- [ ] 编译并运行 Data Lab 的实验框架，完成少量题目，剩余部分在后续周推进。
- [ ] 用 GDB 单步调试一个包含函数调用和指针访问的小程序。
- [ ] 整理第一篇笔记：我以前不理解的一个系统现象、如何验证、现在如何解释。
- [ ] 保持数学和英语；完成一次数据结构基础题复盘。
- [ ] 收集目标院校的官方信息，区分已确定事实与待确认事项。

## 学习与复盘规则

每个主题按“带着问题阅读 → 做题/写代码 → 观察结果 → 用自己的话解释 → 一周后回访”推进。看懂讲解只算开始，能闭卷解释并完成题目或实验才算掌握。

实验卡住时，先确认环境、读说明、构造最小例子，再用调试器查看状态。连续投入两个学习时段仍无进展，就记录假设、错误和已试方法，寻求提示或先完成理论部分。参考答案用于核对；看过答案的实验要能脱离答案重新解释和完成关键部分。

每周复盘填写：

- 本周计划 / 实际用时：
- 能闭卷讲清的三个概念：
- 完成的习题与错题原因：
- 实验成果与验证方式：
- 尚未解决的问题：
- 数学、英语是否连续推进：
- 下周最重要的三件事：

连续两周落后时，依次删去完整 CPU 项目、额外 CSAPP 实验、进阶 xv6 实验和 CS144。优先保留基础理论、代表性实验、数学英语及考点训练。

## 资源入口

以下是制定本计划时核对的入口。选定一届课程后，尽量使用同一版本的讲义、代码和实验说明。

- [CS 自学指南](https://csdiy.wiki/)：课程检索与中文资源入口。
- [CSAPP 指南页](https://csdiy.wiki/计算机系统基础/CSAPP/)与 [CMU 官方实验页](https://csapp.cs.cmu.edu/3e/labs.html)：系统基础与实验材料。
- [CS61C 指南页](https://csdiy.wiki/体系结构/CS61C/)与 [课程官网](https://cs61c.org/)：C、RISC-V、数据通路、流水线与存储层次；官网新学期内容可能尚未齐全，可从指南选择资料完整的往届版本。
- [MIT 操作系统指南页](https://csdiy.wiki/操作系统/MIT6.S081/)与 [2025 年官方日程](https://pdos.csail.mit.edu/6.1810/2025/schedule.html)：xv6 阅读与实验。
- [OSTEP 官方免费教材](https://pages.cs.wisc.edu/~remzi/OSTEP/)：按虚拟化、并发、持久化主题选读。
- [中科大计网指南页](https://csdiy.wiki/计算机网络/topdown_ustc/)：中文讲解、教材与视频入口。

本计划的顺序、周预算、实验取舍和验收标准是根据当前目标制定的个人安排，不是上述课程的官方要求。
