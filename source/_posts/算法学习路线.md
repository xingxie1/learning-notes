## 1. 语法补充

### 1.1 c++的输入输出

cpp的输入输出用的是`cin`和`cout`，这两个函数包含在头文件`<iostream>`中，所以和c语言类似，在cpp的代码开头也需要`#include <iostream>`。在写算法题时，我们会经常使用各种STL容器和STL算法，也就需要包含不同的头文件，非常麻烦，幸运的是，在gcc编译器中，有一个头文件叫`<bits/stdc++.h>`，它包含了我们写算法题时需要的所有头文件，写上这一句`#include <bits/stdc++.h>`，我们就不需要再自己手动`include`一大堆头文件了。需要注意的是，这个头文件只在gcc编译器有，像clang等其他编译器是没有的。并且这个头文件中推荐在写算法题时用，以后工作或者写一些工程代码时，**不要使用**。

在看别人的代码时，应该经常见到这两句出现在代码最开头

```cpp

#include <bits/stdc++.h>
using namespace std;  
```

这第二句的的意思是展开命名空间。cpp为了防止命名冲突，引入了明明空间的概念，就是把一些函数的声明和定义放在命名空间中，在访问时需要指定命名空间。例如`cin`的真正用法其实是`std::cin >> x`。但是一直重复写`std::`非常麻烦，所以为了方便起见，就提前展开命名空间，这样在使用时就不用再加`std::`了。cpp常用的库函数几乎都包含在`std`命名空间中注意，这个写法也是只能在写算法题时使用，以后工作或者写一些工程代码时，**不要使用**。

```cpp
    //c
    int x;
    scanf("%d",&x);
    printf("%d",x);
    //c++
    int x;
    cin >> x;//输入x
    cout << x << endl;//输出x,endl是换行的意思，和'\n'几乎一样

    //如果想连续输入/输出的话，直接在后面加>>/<<即可
    int y,z;
    cin >> y >> z;
    cout << x << " " << y << " " << z;
```

#### 1.1.3 引用

引用的符号是&，(注意这个&和c语言中的取地址符区分开)。
引用的本质其实就是取别名。例如一个人叫张三，他的外号叫小三，那么别人叫他张三或者叫他小三，其实都是在叫他，他都会回应。
用代码解释就是

```cpp

    //我们定义了一个变量x，它的引用是y，那么我们无论修改x，还是修改y，都会改变x。  
    int x = 10;
    int &y = x;
    cout << x << " " << y << endl;//输出10 10
    x = 5;
    cout << x << " " << y << endl;//输出5 5
    y = 1;
    cout << x << " " << y << endl;//输出1 1
```

引用还有一个方便的作用，就是通过函数交换两个变量的值。在c语言中如果让你写一个函数来交换两个变量的值，其实是很麻烦的，需要用到指针。但在cpp中就很方便了。

```cpp

void swap(int& x,int& y) 
{
    int t = x;
    x = y;
    y = t;
}
```

注：cpp库函数中已经写好了`swap`函数，所以以后遇到需要交换两个变量的值的情况时，可以直接调用这个函数，不需要自己再手写了。

引用还有一个很重要的作用是减少开支。

```cpp

void f1(vector<int> a) 
{
    for (int x : a) cout << x << " ";
    cout << endl;
}
void f2(vector<int>& a) 
{
    for (int x : a) cout << x << " ";
    cout << endl;
}

int main()
{
    vector<int> a(10);
    for (int i = 0;i < 10;i++) a[i] = i;
    f1(a);
    f2(a);
}
```

这两个函数看上去几乎一样，但第一个函数(值传递)在传参时会把整个数组a复制一遍，而第二个函数(引用传递)不会，这个复制的过程不仅浪费空间而且浪费时间，所以当我们函数传参较大时，可以优先考虑引用传递。不过要注意，引用传递时，如果我们在函数内修改了这个变量的值，那么这个变量会被真的修改(全局生效)；而如果是值传递，那么在函数内的修改只会在这个函数内生效。
