这篇**示例笔记**用一个最小的流程说明 Git 中三个常见概念：工作区、暂存区和提交历史。

## 修改文件

在工作区编辑文件后，用下面的命令查看状态：

```bash
git status
```

Git 会列出已修改但还没有暂存的文件。

## 暂存改动

确认某个文件的修改准备好提交时，可以运行：

```bash
git add README.md
```

暂存区保存的是**下一次提交准备包含的内容**。如果文件暂存后又被继续修改，新修改还需要再次暂存。

## 提交并查看历史

```bash
git commit -m "更新说明文档"
git log --oneline -5
```

提交会把暂存的内容记录到版本历史。提交信息最好说明这次改动做了什么，方便以后查找。

## 小结

一个常见的顺序是 `git status` → `git add` → `git commit`。遇到不确定的情况，先看状态，再决定下一步。
